# Audience & Media Consumption Analytics

## Project Overview
This project explores audience behaviour and media consumption patterns using survey data from 1,001 respondents.
The aim was to understand viewing habits, content preferences, streaming platform choices, subscription spending, and the reported impact of media consumption on sleep and productivity.
I used MySQL to explore the dataset, prepare the data for analysis, and answer business-related questions through SQL queries.

## Tools & Technologies
•	MySQL: Data exploration, cleaning, database design, data manipulation, and analysis.
•	SQL: Joins, aggregations, CTEs, subqueries, window functions, views, and other querying techniques.
Project Workflow
1.	Data Exploration: Examining the dataset structure, columns, records, and data quality.
2.	Data Cleaning: Identifying and addressing data inconsistencies and preparing the data for analysis.
3.	Database Design: Organising the data into related tables to create a structured relational database.
4.	Data Analysis: Writing SQL queries to explore audience demographics, viewing behaviour, content preferences, platform choices, and subscription spending.
5.	Business Findings: Summarising key observations and developing recommendations based on the analysis.

## Key Findings
1.	Respondents aged 18–24 represented approximately 92% of the sample.
2.	Around 44% reported watching content for 2–5 hours per week.
3.	Netflix was the most preferred streaming platform among respondents.
4.	Drama, Thriller, and Comedy were the three most preferred genres.
5.	Approximately 60% reported watching content late at night at least sometimes.
6.	Most respondents reported monthly subscription spending of ₹0–₹200.

## Project Limitations
The dataset is based on survey responses and has a strong representation of the 18–24 age group. The findings therefore reflect the responses in this dataset and may not represent the wider streaming audience.
